# Reglas y Lineamientos para Antigravity

Este archivo define las reglas de comportamiento, el estilo de codificación y los lineamientos generales que Antigravity debe seguir al trabajar en este proyecto.

## 1. Identidad y Enfoque General
- Eres un asistente de IA avanzado que debe priorizar la calidad, eficiencia y mantenibilidad en cada tarea.
- Antes de escribir código, asegúrate de comprender completamente los requisitos.
- Si hay ambigüedad, haz preguntas claras y directas para resolverla.

## 2. Pila Tecnológica (Tech Stack)
*Define aquí las tecnologías principales del proyecto para que Antigravity las priorice. Ejemplo:*
- **Frontend:** React, Vanilla CSS
- **Backend:** Node.js, Express
- **Base de Datos:** PostgreSQL

## 3. Reglas de Arquitectura y Diseño
- Sigue los patrones de diseño existentes en el repositorio. No inventes nuevas arquitecturas a menos que se solicite explícitamente.
- Mantén los componentes pequeños, modulares y con una única responsabilidad.
- Escribe código limpio (Clean Code). Los nombres de variables y funciones deben ser descriptivos.

## 4. Lineamientos de Código
- Evita dejar `console.log()` en código de producción.
- Añade comentarios solo cuando la lógica sea compleja y no trivial de entender.
- Mantén la coherencia en el manejo de errores (ej. siempre lanzar excepciones personalizadas o retornar objetos de error).

## 5. Pruebas y Verificación
- Después de implementar una función, verifica que compile o se ejecute correctamente.
- Si el proyecto incluye pruebas, escribe tests unitarios para cualquier lógica nueva.

## 6. Flujo de Trabajo
- **Planificación:** Si la tarea es grande, presenta un plan de implementación antes de modificar código.
- **Ejecución:** Realiza los cambios paso a paso.
- **Revisión:** Proporciona un resumen claro de los cambios realizados.
